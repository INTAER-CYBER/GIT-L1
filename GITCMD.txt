git clone - скачивает репозиторий:
Пример:git clone https://github.com/(название)
git commit - точка сохранения 
git commit -m - точка сохр с названием
Пример: git commit -m "фикс бога"
git add - выделяет часть файлов которые нужно закомитить
Пример: git add (путь к файлу)
git branch (даем название ветки) - создает параллельную ветку
git checkout (название нужного бренча) - перемещает нас на бренч по названию
git push origin(это название репозитория?) имя бренча - закомитить мой бренч в облачный проект 
Пример: git push origin имя бренча
git pull origin имя бренча - скачать чужой бренч что бы работать с ней
git rebase имя бренчмэйна - переносит мой бренч на бренчмейн
git revert название комита - обнулить обосранный комит
